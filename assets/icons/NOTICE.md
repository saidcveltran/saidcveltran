# Icons

The icons in this folder come from [Simple Icons](https://simpleicons.org/), version
`16.35.0`, fetched from `https://cdn.jsdelivr.net/npm/simple-icons@16.35.0/icons/<slug>.svg`.

Simple Icons is released under CC0 1.0 (public domain dedication). The logos themselves remain
trademarks of their respective owners and are shown only to identify the technologies used.

Slugs used: typescript, javascript, nodedotjs, python, godotengine, blender, cloudflare, git, discord.

Apify is not part of Simple Icons, so the stack row shows a plain "Ap" monogram instead of a logo.
