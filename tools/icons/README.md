# Social icons

Glyph shapes used by the profile buttons. Each file is a single-source asset kept unmodified.

| File | Source | Licence of the artwork file |
| --- | --- | --- |
| x, tiktok, instagram, discord, github, devdotto, producthunt, itchdotio | `simple-icons@16.36.0` (npm), `icons/<slug>.svg` | CC0 1.0 |
| apify | `https://apify.com/img/apify-logo/apify-symbol-200x200.svg` (the company's own logo file) | not CC0 |

The shapes are the networks' own logos. Their names and logos are trademarks of their owners and are used here
only to identify links to my accounts on those services.
